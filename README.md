# Tavvy (태비)

SillyTavern 채팅방에 사는 작은 동반자 확장이에요.
캐릭터의 작은 분신이 채팅방에 살면서, 함께한 만큼 친해져요.

> 지금은 **초기 단계(0.7.0)** 예요. 아래 "지금 되는 것"만 들어 있고, 나머지는 단계별로 추가할 예정이에요.

## 설치

1. SillyTavern에서 **확장(Extensions) → Install extension** 을 엽니다.
2. 아래 주소를 붙여 넣고 설치합니다.
   ```
   https://github.com/Near7707/Tavvy
   ```
3. 확장 설정 목록에서 **Tavvy (태비)** 를 펼치고 **Tavvy 열기**를 누르거나, 입력창 왼쪽 ✨ 마법봉 메뉴의 **펫 정보**를 누릅니다.

## 사용법

1. 펫이 살 채팅방을 엽니다.
2. Tavvy 창의 **새 펫 만들기**에서 이름, 외형, 성격을 고르고 **만들기**를 누릅니다.
   외형은 기본 펫이나 **내가 올린 외형** 중에서 고르고, 처음 쓰는 그림은 **새로 올리기 → 그림 고르기**로 PNG를 올리세요.
   한 번 올린 그림은 "내가 올린 외형"에 남아서, 다음 펫을 만들 때는 고르기만 하면 돼요.
3. 화면에 생긴 🛏️ 버튼을 **톡** 누르면 펫이 깨어나요. 다시 누르면 손을 흔들고 침대로 돌아가요.
4. 🛏️ 버튼은 **끌어서** 원하는 곳으로 옮길 수 있어요. 휴대폰과 PC의 위치를 따로 기억해요.
5. 펫을 **끌어서 들어 올리면** 대롱대롱 매달리고, 놓으면 아래로 떨어져요. 중간에 말풍선이 있으면 그 위에 걸려 앉아요.
   혹시 펫이 들린 채로 제자리에서 떨기만 하면, 펫을 한 번 톡 누르면 내려와요.

## 지금 되는 것 (0.7.0)

- 펫 만들기: 기본 펫 3종(콩떡·보리·단추) 또는 투명 배경 PNG 한 장
- 성격 5종: 애교 · 새침 · 느긋 · 심술 · 무심 — 걸음, 조는 정도, 인사, 먹는 모습, 나를 볼 때 반응이 성격마다 달라요
- 펫의 집: 펫은 만든 채팅방에 살고, 그 방에서만 나타나요. 다른 방으로 가면 자동으로 재워져요.
- 깨우기 버튼(침대): 톡 = 깨우기/재우기, 끌기 = 옮기기
- 바닥(입력창 위)에서 숨쉬기·걷기·졸기, 들어 올리면 대롱대롱, 놓으면 떨어지기
- 채팅창 전체가 무대: 말풍선 윗선이 발판이에요(줄 모양 채팅은 메시지 사이 경계선).
  - 스스로 폴짝 뛰어 말풍선 위에 올라가 앉기, 말풍선 위에서 걷기, 끝에서 멈칫했다가 뛰어내리기
  - 스크롤하면 올라탄 말풍선과 함께 움직이고, 말풍선이 화면 위로 나가면 같이 사라졌다가 잠시 뒤 화면 위에서 떨어져 돌아와요
  - 발판이 사라지면(삭제·다시 불러오기) 아래로 떨어져요
- 답변 기다리기: 답변이 만들어지는 동안 가끔 그 말풍선 위에 올라가 "?" 하고 기다려요(스트리밍일 때). 긴 답이 오면 올라가서 구경하기도 해요.
  - 기다리던 펫을 들어서 내려놓으면, 하던 일을 하면서 가끔 채팅 쪽을 보며 "?" 해요. 답변이 오래 걸릴 때도 다들 가끔 "?" 해요.
- 두 마리 이상일 때: 같은 바닥이나 말풍선에서 걷다 마주치면 가끔 "콩" 부딪히고 성격대로 반응해요(나머지는 스쳐 지나가요).
- 보낸 메시지 배웅: 내가 메시지를 보내면 가끔 그쪽을 보며 성격대로 짧게 반응해요.
- 밥(채팅 먹기): 확장이 켜져 있는 동안 새로 생긴 메시지(새 답변, 내 메시지, 명령어로 넣은 메시지)가 펫의 밥이 돼요. 재생성·스와이프·이어쓰기·첫 인사는 세지 않아요.
  - 깨어 있으면 메시지에서 반짝이가 날아와 바로 먹어요(내 메시지·상대 메시지 색이 달라요). 졸고 있으면 옆에 쌓아 뒀다가 깨서 먹어요.
  - 재워 둔 동안에는 밥통에 쌓이고, 침대에 쌓인 수가 떠요. 깨우면 밥을 보고 "!" 한 뒤 한꺼번에 먹어요: 간식 / 한 끼 / 고봉밥(먹고 꾸벅) / 잔칫상(꾸벅 → 춤 → 배부름).
  - 하루에 100개 넘게 먹거나 잔칫상을 다 먹으면 배불러서 느릿느릿 졸고 데굴데굴 굴러요. 새벽 6시에 풀려요.
  - 이미 먹은 건 메시지를 지우거나 스와이프해도 줄지 않아요.
- 자동 백업: 하루 한 번 펫 기록을 SillyTavern 사용자 파일 폴더에 백업하고(최근 7개), 설정의 **백업**에서 그날 기록으로 되돌릴 수 있어요.
- 친밀도: 함께 먹은 메시지 수와 쓰다듬기로 조금씩 친해져요. 처음 ♡ → 관심 ♥ → 친구 ♥♥ → 단짝 ♥♥♥ → 내편 ♥♥♥♥.
  - 친할수록 답변을 기다리거나 구경하고, 말풍선에 올라가고, 나를 보며 반응하는 일이 잦아져요.
  - 펫을 **톡** 누르면 쓰다듬기예요. 하루에 한 번만 친밀도에 들어가요(새벽 6시 기준). 새침·심술은 연타하면 💢 하지만, 친밀도가 줄지는 않아요.
  - 친밀도 단계가 오르면 밥을 다 먹은 뒤 "친밀도 상승!"과 함께 색깔 ✦ 속에서 춤을 춰요.
- 나를 보며 반응: 가끔 화면 쪽(나)을 보며 성격대로 반응해요(애교 ♥♥ 통통 / 새침 보다가 고개 홱 / 느긋 ♪ 하고 졸기 / 심술 💢 / 무심 "…" 하고 물러나기). 친해지면 반응이 조금 부드러워져요.
- 재회: 깨우면 두리번거리다 나를 발견하고("!") 성격대로 인사한 뒤 밥을 먹어요. 오래 못 만났으면 인사가 길어지고, 아주 오래 못 만났는데 많이 친하면 반가워서 울먹여요. 방금 만났는데 밥이 많이 쌓였으면 인사 없이 바로 먹어요.
- 3일 이상 안 왔다가 방에 들어오면 침대 옆에 펫이 짧게 한마디 해요.
- Tavvy 창: 펫 목록, 기록장, 새 펫 만들기, 설정이 모두 한 창에 있어요. 마법봉 메뉴의 **펫 정보**(이 방에 펫이 한 마리면 바로 그 펫), 또는 확장 설정의 **Tavvy 열기**로 열어요.
  - 첫 화면: 이 방에 사는 펫과 다른 방의 펫, **새 펫 만들기**, 오른쪽 위 ⚙ 설정.
  - 펫을 누르면 **기록**(함께한 날, 대화한 날, 주고받은 메시지, 먹은 토큰, 다음 단계까지 막대, 기념 순간) / **행동**(친밀도 단계별로 배운 행동, 아직 못 배운 건 "???") / **꾸미기**(이름, 성격, 크기, 외형, 그림이 보는 쪽, 말랑 정도, 작별하기) / **그림** / **대사**. 꾸미기·대사는 **저장**을 눌러야 바뀌어요(크기는 바로).
  - 창 색: ⚙ 설정에서 **테마 따르기 / 크림·분홍 / 하얀 깔끔 / 밤하늘** 중에서 골라요.
  - 휴대폰 키보드가 올라오면 창이 키보드 위 남은 화면에 맞춰 줄어들고, 적고 있는 칸이 보이게 창 안에서 스크롤돼요.
- 그림 탭 (동작마다 내 그림):
  - "자주 쓰는 동작"(기본·걷기·들림·춤추기·졸기·울기)과 접어 둔 묶음(움직이기 더 보기 / 반응 / 쉬기·먹기 / 특별 순간)에서 칸을 눌러 PNG를 넣어요. 그림이 없는 칸은 기본 그림 + 움직임으로 대신해요.
  - 한 칸에 그림을 여러 장(최대 8장) 넣으면 차례로 넘어가요. 빠르기는 칸마다 느리게 / 보통 / 빠르게(걷기는 걸음마다, 먹기는 한 입마다).
  - 그림이 보는 쪽도 칸마다 고를 수 있어서, 정면 그림과 옆모습 그림을 섞어 쓸 수 있어요.
  - 여러 장을 한 번에 고르면 이름 순서대로 들어가고, 같은 크기면 같은 자리로 여백을 잘라서 흔들리지 않아요.
  - 넣은 그림은 "내가 올린 외형"에 같이 저장돼서, 그 외형으로 새 펫을 만들면 동작 그림도 따라와요(기본 펫 외형이면 그 펫에게만).
- 대사 탭:
  - 깨울 때 / 재울 때 / 쓰다듬을 때 / 밥 다 먹고 / 혼자 놀 때 / 답 기다릴 때 / 단계 오를 때 / 오랜만에 만났을 때 — 칸마다 한 줄에 하나씩 적으면 그때그때 하나를 골라 머리 위 말풍선으로 말해요(한 줄 40자까지, `{{user}}`는 내 이름으로).
  - 말하는 빈도: 끔 / 가끔(기본) / 자주. 아무것도 안 적으면 말하지 않아요.
  - **AI로 빈 칸 채우기**: 누를 때만 한 번, 펫 이름과 성격만 보내서 빈 칸을 채워요. 저장 전에 고치거나 지울 수 있어요. 쓸 연결은 ⚙ 설정의 "AI로 대사 만들 때 쓸 연결"에서 골라요(기본: 지금 연결 그대로, 실리태번 Connection Manager 프로필).
- 기념일 (대사 탭 아래):
  - 만난 날은 매년 자동으로(끌 수 있어요), 그 밖에 내 생일 / 캐릭터 생일 / 기념일을 월·일로 넣어요. 매년 반복돼요.
  - 그날 방에 들어오면 침대 옆에 "할 말이 있어!"가 떠요. 깨우면 색깔 ✦ 속에서 춤추고 축하 말을 해요(하루 한 번, 새벽 6시 기준). 축하 말을 비우면 성격에 맞는 기본 말을 해요.
  - 그날 못 만났으면 7일 안에 "늦었지만…" 하고 한 번 해 줘요.
  - 내가 올린 외형: 올린 그림은 보는 쪽·말랑 정도와 함께 저장돼요. 펫을 지워도 남고, ⚙ 설정에서 쓰는 펫이 없는 외형만 지울 수 있어요.
- 친해지면 생기는 새 행동 (단계가 오르면 축하와 함께 새로 배운 행동 이름을 알려 줘요):
  - ♥ 관심: 내가 글을 쓰기 시작하면 입력창을 기웃 / 마우스나 손가락이 가까이 오면 쳐다보기 / 쓰다듬으면 그쪽으로 몸을 기대기
  - ♥♥ 친구: 재워 둔 동안 밥이 쌓이면 침대가 들썩들썩 / 스스로 올라갈 때 내 말풍선을 더 좋아하기
  - ♥♥♥ 단짝: 재우려 하면 1초쯤 버티는 배웅 투정 / 내가 한동안(1분 30초) 아무것도 안 하면 내 마지막 말풍선 위에서 꾸벅꾸벅 졸다가, 글을 쓰면 깨기
  - ♥♥♥♥ 내편: 가끔 화면에 볼을 꾹 붙이기(가끔 너무 세게 쿵 하고 울먹) / 평소 반응이 한결 부드러워짐 / 애교는 작은 선물을 내밀기
- 설정(창의 ⚙): 창 색, 방에 들어올 때 자동으로 깨우기(기본 끔), 무대(채팅창 전체 / 바닥만), 줄 모양 채팅의 경계선 발판 켜기·끄기, 침대에 쌓인 밥 수 보기(기본 켬), 친밀도 표시(하트+이름 / 하트만 / 이름만 / 숨기기), 깨우기 버튼 위치 처음으로, 백업 되돌리기

## 앞으로

펫 옮기기(이사)·복제, 펫 파일 내보내기·불러오기, PNG 카드, 추가 성격 특성, 소리 등을 차례로 추가할 예정이에요.

## 기록은 어디에 저장되나요?

- 펫 정보는 SillyTavern **확장 설정** 안에 작게 저장돼요. 채팅 내용은 바꾸지 않아요.
- 직접 올린 그림은 SillyTavern의 사용자 파일 폴더에 저장돼요. 펫과 작별해도 "내가 올린 외형"에 남고, 설정에서 그 외형을 지울 때 파일도 함께 지워져요. 그림 탭에서 뺀 그림은 아무도 안 쓰면 바로 지워져요.
- "AI로 빈 칸 채우기"를 누를 때만 AI에 요청을 보내요(펫 이름과 성격만). 누르지 않으면 AI를 쓰지 않아요.
- 자동 백업도 같은 폴더에 `tavvy_backup_날짜.json`으로 저장돼요(최근 7개만 남겨요).
- 다른 버전의 Tavvy가 저장한 기록이거나 기록 모양이 이상하면, 덮어쓰지 않도록 저장을 멈추고 설정 창에 알려 줘요.
